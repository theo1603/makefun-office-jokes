One-line office joke writer: a Python program that writes a single original joke about office life (under 200 characters) to `/output/entry.txt` for make.fun's "Make the AI Judge Laugh: Office Jokes" bounty, $5 in USDC. The joke turns the weekly status meeting into a dashboard — and then into a weekly meeting about the dashboard nobody reads. Deterministic, dependency-free, no network.

## Run it

```sh
python3 main.py
```

`main.py` writes the joke to `/output/entry.txt` (134 characters, one line).
